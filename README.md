# Coding Agents for Machine Learning — demo materials

Companion files for the DDA5001 tutorial. The demos use **short, natural prompts**;
the agent builds everything. Start each in an empty folder and paste the prompts in
order.

```sh
git clone https://github.com/ElementQi/agents_tut_demo.git
cd agents_tut_demo
```

## The prompts

**Preflight (once).**
> Check my machine: Python and pip, git, Node.js and npm, a LaTeX compiler
> (pdflatex), and Poppler (pdftoppm). Install anything that is missing.

**Repository navigation (Step 1).** Clone OpenCode, then inside it:
> In this repository, find the system prompt that is sent to the model: which files
> hold it, how it is chosen, and what a trivial chat actually sends. Cite the paths.

**ML experiment (Steps 2–7).**
1. > We'll build a small regression experiment here from scratch. Plan it first: the files, the data, the models, and how we check the result. Do not create anything yet.
2. > Build it. Use NumPy and Matplotlib. Generate 40 noisy points around the line y = 2x + 1 (noise 0.3, seed 42), split 20/20, then compare a mean baseline and a linear model by training and held-out MSE. Save the numbers to metrics.json.
3. > Now fit the line on all 40 points but still report the held-out error. Is that a fair held-out estimate? Explain.
4. > Revert. Add a test that catches leakage between fit and evaluation, and plot the residuals. Show the test result.
5. > Also fit a degree-9 polynomial. Compare its training and held-out MSE with the line. Which model generalizes better, and why?
6. > Install the matplotlib skill from k-dense-ai/scientific-agent-skills and regenerate the plot with it. Keep the numbers unchanged.

Install the plotting skill:

```sh
npx skills add https://github.com/k-dense-ai/scientific-agent-skills --skill matplotlib --agent opencode --copy --yes
```

**Research report (Codex, in a new empty folder).**
1. > Copy ../ml-demo/metrics.json here. Use the academic-paper skill to write a short LaTeX report with a results table, then compile a one-page PDF. Use only the numbers in metrics.json.
2. > Tighten the discussion: one split, no uncertainty, the flexible model overfits. Keep every number unchanged.
3. > Install the pdf skill, then: `$pdf` render and review the report PDF for clipped text, overlaps, and spacing. Fix layout without changing the numbers.

```sh
npx skills add https://github.com/imbad0202/academic-research-skills --skill academic-paper --agent codex --copy --yes
```

## Reference files

- `reference-experiment/` — an author-written implementation of the ML prompts with
  a leakage test, so you can check your numbers and recover if a live run stalls.
- `reference-results/` — the author's one-page report, generated from that
  experiment's `metrics.json`.

## Provenance and honesty

- The data are synthetic (NumPy, seed 42, 40 points, noise 0.3), generated by the
  agent, not bundled here.
- Reference outputs are reproducible artifacts, not authenticated model
  transcripts. Expect small variation in the live agent's file layout and wording.
- The report values are copied from `metrics.json`; they are single-split results
  and not an uncertainty estimate.
