# Coding Agents for Machine Learning — demo materials

Companion files for the DDA5001 tutorial. The demos are **prompt-only**: start in
an empty folder, paste the prompts in order, and let the agent build everything.
Clone this repository for the prompt list and the author references.

```sh
git clone https://github.com/ElementQi/agents_tut_demo.git
cd agents_tut_demo
```

## What is here

- **`PROMPTS.md`** — the two prompt sequences, copy-pasteable. This is the
  takeaway.
- **`reference-experiment/`** — an author-written implementation of Demo A with a
  leakage test, so you can check your numbers and recover if a live run stalls.
  It is not a recording of a model session.
- **`reference-results/`** — the author's one-page report for Demo B, generated
  from the experiment's `metrics.json`.

## Prerequisites

Python 3.13, Node.js LTS, OpenCode, Codex CLI, and (for the report) a LaTeX
distribution plus Poppler. You do **not** need to install these by hand: the first
prompt (Step 0 in `PROMPTS.md`) asks the agent to check the machine and install
whatever is missing.

## The two demos

**Demo A — OpenCode (empty folder).** Plan, build a mean baseline and a linear
model on a 20/20 split, inspect the evaluation, reject a leakage variant, add a
test and a residual plot, compare a degree-9 polynomial, and regenerate the plot
with a published matplotlib skill. Reference seed-42 values: mean baseline held-out
MSE 1.7700; linear 0.1035; degree-9 polynomial 0.1429.

**Demo B — Codex (new empty folder).** Copy the experiment's `metrics.json`, use
the `academic-paper` skill to write a short LaTeX report, compile a one-page PDF,
and review the rendered page with the OpenAI `pdf` skill.

## Provenance and honesty

- The data are synthetic (NumPy, seed 42, 40 points, noise 0.3) and generated by
  the agent, not bundled here.
- Reference outputs are reproducible artifacts, not authenticated model
  transcripts.
- The report values are copied from `metrics.json` at four decimal places; they are
  single-split results and not an uncertainty estimate.
